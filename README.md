Palmera Heat is an original open-world crime game set in the fictional city of Vista Palmera. Explore on foot and by car, steal and drive cars, run from a five-star wanted level with police chases, fight with mouse-aim combat, and play a six-mission story arc — with traffic, pedestrians, a chop shop, hidden cash stashes, a HUD with a live minimap, and localStorage saves. Plain JavaScript and canvas, no libraries, no network requests: it runs offline from the static files in game/.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
